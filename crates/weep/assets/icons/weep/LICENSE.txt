WEEP's own icon drawings (MIT, like the rest of WEEP): panel toggles, the tools
grid, the terminal, the collaboration mark, the git branch, the logo, the
file-type monograms, the gutter's run triangle, the status badge's check, the
problems widget's sliders and its error mark (a circle and an exclamation,
painted in two colours). Drawn on the same 16-unit grid with 1 px strokes as the
expui set beside them, so the two mix in one toolbar. `weep.ico`, the Windows
application icon, is the logo rendered by tools/windows/make_icon.py.
