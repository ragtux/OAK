Fleet's shape, native.

A code editor in Rust on GPUI, shaped like JetBrains Fleet: its islands, its tools, its theme and keymap files, its measured sizes. No JVM, no account, no telemetry.

What is in it today

Milestones M0 to M6 are built. M7, Smart Mode over LSP, has its first pass in.

Editor Built

Everything Fleet does to text

Multiple carets, find and replace, folding, soft wrap, the indenter, auto-pairs, .editorconfig, autosave, one document per file across tabs and splits. Highlighting is tree-sitter on Fleet's textAttributes keys.

Workbench Built

Goto, Search, Files, Settings

The Goto popup with its preview, find and replace across the workspace, the Files tree, Fleet's menus and dialogs, and the Settings pages as a tab.

The tools →

Git · Terminal · Run Built

The tools around the code

Status, staging, commit, history, blame, side-by-side Changed Files, push and pull; a terminal on a real PTY; .fleet/run.json configurations.

Smart Mode In progress

Language servers, Fleet's surface

Diagnostics, completion, navigation, usages, rename, quick fixes and reformat through rust-analyzer — the server Fleet's Rust Smart Mode runs too. The debugger over DAP comes next.

The roadmap →

Where it is, plainly

v0.1.0, a first pre-release. It saves files in place, autosave included — keep your work in version control. The archives are unsigned, and sizes on the newest surfaces are still estimates.

Platforms

Linux, Windows, macOS

An archive each, or stable Rust from source.

Languages

Rust, JSON, TOML, Markdown

Those four have grammars; Rust gets rust-analyzer. Anything else opens as text.

Not yet

Known gaps

No debugger, inlay hints, code vision, inline rename or snippets, and no server but rust-analyzer.
